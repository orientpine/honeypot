## INSTRUCTION

### Image Purpose
핵심 성과 지표를 공공기관 보고형 본문 슬라이드로 구조화하여 도입 효과를 정량적으로 전달한다.
도입률과 성과 수치를 한 화면의 흐름으로 배치해 확산 단계의 실행 판단 근거를 제공한다.

### Target Audience
정책 심의 위원, 정부 지원사업 기획자, 제조 전환 실무 책임자가 빠르게 핵심 수치를 비교하고 의사결정할 수 있는 가독성을 목표로 한다.

### Key Message
도입률 34%, 생산성 향상 23%, 불량률 감소 18%는 스마트 팩토리 도입 효과를 입증하며 확산 정책의 정밀 설계를 요구한다.

### Scene Description
상단 배너에는 본문 제목이 단정하게 배치되고 중앙에는 세 개의 직사각형 본문 블록이 동일 폭으로 정렬된 보고서형 구도가 형성된다.
좌측 블록은 도입 현황과 대상군 특성을 담고 중앙 블록은 세 개의 핵심 성과 지표를 수직으로 정렬해 가장 높은 주목도를 확보한다.
우측 블록은 확산 단계의 제약과 실행 방향을 요약해 지표 해석이 정책 과제로 자연스럽게 이어지도록 구성한다.
각 블록 상단에는 번호 배지 01, 02, 03이 배치되어 읽기 순서를 고정하고 블록 간 간격은 균일하게 유지된다.
좌측에서 중앙, 중앙에서 우측으로 이어지는 연결선은 좌상단에서 우하단으로 흐르는 정책 실행 동선을 시각화한다.
배경은 밝고 차분한 단색 기반으로 유지하며 상단 배너와 하단 주석 분리선이 문서 프레임을 안정적으로 고정한다.
하단에는 기준일과 출처를 작은 캡션으로 배치해 수치의 근거성과 공식 보고의 신뢰감을 강화한다.
No watermarks, no blurry text, no placeholder brackets, no duplicated labels, no random artifacts, no photo textures.

### Rendering Style
- surface: 모든 본문 정보는 선명한 실선 경계의 직사각형 패널로 통일하고 내부는 명확한 텍스트 영역으로 분할한다.
- background: 단색 오프화이트 캔버스 위에 상단 배너와 하단 구분선을 두어 공공 문서 프레임을 만든다.
- corners: 패널과 배너의 모든 모서리는 직각으로 유지하여 형식적 안정성을 강화한다.
- connectors: 블록 간 흐름은 과장 없는 실선 화살표로 처리해 단계 이동을 명료하게 보여준다.
- decorations: 번호 배지와 최소 장식 불릿만 허용하고 화려한 장식 요소는 배제한다.
- spatial: 상단 제목 영역, 중앙 3블록 본문, 하단 근거 주석 영역의 수직 계층을 유지한다.
- metaphor: 데이터 기반 정책 집행 보드 위에 성과가 축적되는 공공 실행 대시보드 은유를 사용한다.
