## INSTRUCTION

### Image Purpose
도입 장애요인과 대응 전략을 정부 보고형 본문 슬라이드로 정리해 실행 우선순위를 명확히 제시한다.
제약 요인과 대응 조치가 일대일로 연결되는 구조를 통해 확산 단계의 정책 실행성을 높인다.

### Target Audience
정책 집행 부서, 지원사업 운영기관, 제조기업 전환 리더가 제약과 대응의 연결 관계를 빠르게 검토할 수 있는 실무 중심 가독성을 제공한다.

### Key Message
스마트 팩토리 확산은 초기 투자비, 역량 격차, 시스템 연계 비용을 단계별 대응 전략으로 해소할 때 성과 확장으로 이어진다.

### Scene Description
상단에는 주제 배너가 화면 폭을 안정적으로 차지하고 중앙 본문은 좌측 문제 영역, 중앙 대응 전략 영역, 우측 기대 효과 영역의 세 패널로 균형 배치된다.
좌측 패널에는 주요 장애요인이 위에서 아래로 정렬되고 중앙 패널에는 각 장애요인에 대응하는 정책과 현장 실행 전략이 단계 순서대로 배치된다.
우측 패널에는 대응 전략 적용 후 기대되는 효과를 정량과 질적 개선 문장으로 요약해 실행 동기를 강화한다.
각 패널 상단에는 01, 02, 03 번호 배지가 들어가 읽기 동선을 고정하며 패널 크기와 간격은 동일하게 유지된다.
좌측에서 중앙, 중앙에서 우측으로 이어지는 연결선은 좌상단에서 우하단으로 이동하는 정책 실행 흐름을 직관적으로 보여준다.
배경은 밝은 단색 문서면으로 유지하고 상단 배너와 하단 주석선이 공공기관 보고 포맷의 프레임을 완성한다.
하단에는 기준일과 출처를 배치해 근거 기반 보고 형태를 강화하고 과도한 장식이나 입체 효과는 제거한다.
No watermarks, no blurry text, no placeholder brackets, no duplicated labels, no random artifacts, no dramatic lighting.

### Rendering Style
- surface: 모든 항목은 직사각형 박스 패널 내부에서 정렬하고 헤더와 본문 구획을 분명히 나눈다.
- background: 오프화이트 배경과 상단 배너를 사용해 안정적인 보고서 표면을 만든다.
- corners: 패널, 배너, 연결 상자의 모서리는 모두 직각으로 처리한다.
- connectors: 장애요인에서 대응전략, 대응전략에서 기대효과로 이어지는 단방향 실선 흐름을 유지한다.
- decorations: 번호 배지, 단순 구분선, 최소 불릿만 사용하고 복잡한 장식은 배제한다.
- spatial: 상단 제목 영역, 중앙 3패널 본문, 하단 주석 영역의 3단 공간 구조를 고정한다.
- metaphor: 정책 대응 파이프라인이 성과로 전환되는 실행 체계 메타포를 채택한다.
