## INSTRUCTION

### Image Purpose
디지털 전환의 성과와 장애요인을 시각적 메타포로 대비시키는 교육용 일러스트레이션. 텍스트 없이 좌우 장면의 극적 대조를 통해 성공적인 디지털 전환과 실패한 전환의 차이를 직관적으로 전달한다.

### Target Audience
제조업 경영진, 디지털 전환 담당자, 정책 입안자, 기술 도입을 고민하는 기업 리더. 추상적인 성과 지표를 시각적으로 이해하고자 하는 청중.

### Key Message
디지털 전환의 성공은 기술 도입뿐 아니라 조직 문화, 인력 역량, 체계적 실행 계획의 조화에 달려 있다.

### Visual Style
Kurzgesagt 풍 시각 스토리텔링. 채도 높은 플랫 벡터 일러스트로 복잡한 개념을 한 장면에 담는다. 텍스트 없이 시각적 메타포와 캐릭터 행동으로만 정보를 전달한다. 좌우 대비 레이아웃으로 성공과 실패를 극적으로 표현한다.

### Rendering Style
- 서피스: 플랫 벡터 일러스트레이션. 둥근 기하학적 형태와 부드러운 곡선. 각 도형은 단일 고채도 색상으로 채움. 테두리 없음. 그림자는 같은 색의 어두운 톤으로 최소한만 사용.
- 배경: 어두운 단색(딥 스페이스 #0D1B2A) 또는 미세한 대각선 그라데이션. 배경에 미세한 별/입자/보케 2-4개 허용. 배경은 전경 요소를 돋보이게 하는 무대 역할.
- 코너/엣지: 모든 형태에 큰 라운딩 적용. 날카로운 모서리 없음. 캐릭터와 사물 모두 부드럽고 친근한 형태.
- 연결선: 연결선 대신 시각적 근접성과 행동으로 관계를 표현. 필요 시 빛나는 입자 흐름(glowing particle stream) 또는 에너지 선(energy beam)으로 연결.
- 시각 장식: 빛나는 글로우 효과(glow), 작은 빛 입자(particles), 반투명 원형 보케, 에너지 파동(ripple). 플랫하되 깊이감을 빛과 레이어로 표현.
- 공간 구성: 풀블리드(edge-to-edge) 장면. 전체 캔버스를 좌우 두 개의 대비되는 장면으로 활용. 전경-중경-후경의 3레이어 깊이감. 핵심 요소는 화면의 1/3 지점에 배치(삼분법). 세이프 존: 모든 핵심 시각 요소(캐릭터, 주요 오브젝트, 행동의 결과물)는 캔버스 가장자리에서 5% 이상 안쪽에 완전히 포함되어야 한다.
- 시각 메타포: 시각 스토리텔링. 복잡한 개념을 일상적 장면이나 판타지 세계로 번역. 추상 개념을 물리적 사물로 의인화. 스케일 대비(거대 vs 미소)로 중요도 표현. 인과관계를 장면 내 행동 시퀀스로 보여줌.

### Content Placement
캔버스를 좌우로 나누어 극적인 대비를 표현한다. 좌측은 밝고 생기 넘치는 성공의 정원이고, 우측은 어둡고 혼란스러운 실패의 미로다. 좌측 성공 영역: 밝은 초록색으로 빛나는 공장이 정돈된 정원처럼 펼쳐져 있고, 로봇들이 조화롭게 움직이며 작업하고 있다. 밝은 노란색 빛이 위에서 내려와 모든 것을 비추고 있으며, 작은 캐릭터들이 행복한 표정으로 함께 일하고 있다. 데이터 흐름이 깨끗한 시안색 선으로 정렬되어 있고, 생산 결과물들이 반짝이며 쌓여가고 있다. 우측 실패 영역: 어두운 회색과 검은색으로 뒤덮인 공장이 엉킨 전선과 혼란스러운 기계들로 가득 차 있다. 로봇들이 방향을 잃고 충돌하고 있으며, 데이터 흐름이 끊어지고 얽혀 있다. 작은 캐릭터들이 혼란스러운 표정으로 헤매고 있고, 생산 결과물이 쌓이지 않고 흩어져 있다. 중앙에는 보이지 않는 경계선이 있어 두 세계를 명확히 분리한다. 좌측의 밝은 에너지가 우측의 어둠과 극적으로 대비된다. No text, no labels, no numbers, no watermarks, no blurry elements.

## CONFIGURATION

### Canvas Settings
- resolution: 3840x2160
- aspect_ratio: 16:9
- layout: contrast

### Background Treatment
- base: 어두운 단색 배경 (딥 스페이스 #0D1B2A)
- texture: 미세한 대각선 그라데이션
- accent_elements: 별/입자/보케 2-4개

### Color Palette
- primary: #0D1B2A (딥 스페이스) - 배경, 깊이감
- secondary: #FF6B35 (따뜻한 오렌지) - 성공 영역의 에너지, 생명력
- accent: #4ECDC4 (시안 틸) - 성공 영역의 데이터 흐름, 기술 요소
- foreground: #E8F5E9 (민트 화이트) - 성공 영역의 전경 요소, 하이라이트

### Layout Structure
Contrast layout with left-right split:
- Left side (Success): 밝은 초록색과 노란색으로 빛나는 번영하는 공장 정원
- Right side (Failure): 어두운 회색과 검은색으로 뒤덮인 혼란스러운 공장 미로
- Center: 보이지 않는 경계선으로 두 세계를 명확히 분리
- Depth: 각 영역에서 전경-중경-후경의 3레이어 깊이감

### Typography
All Korean text must be rendered with crisp, perfectly formed characters using heavy-weight Gothic-style sans-serif fonts. Each Korean syllable block must be complete and legible. Use Bold weight (700+) for titles, Medium weight (500) for body text.
**CRITICAL: This theme renders NO text in the image. All information is conveyed through visual elements, character actions, and spatial composition.**
