## INSTRUCTION

### Image Purpose
스마트 팩토리 생태계를 교육용 개념 일러스트로 묘사하여 기술 요소와 산업 주체의 연결 구조를 직관적으로 전달한다.
문자 정보 없이 장면 구성만으로 생산 현장, 데이터 흐름, 자동화 의사결정의 상호작용을 이해하게 한다.

### Target Audience
제조혁신에 관심 있는 일반 대중, 산업 실무자, 정책 담당자가 텍스트 없이도 핵심 개념을 해석할 수 있는 시각적 명료성을 목표로 한다.

### Key Message
스마트 팩토리는 사람, 설비, 데이터, 에너지, 공급망이 하나의 순환 생태계로 연결될 때 지속적으로 진화한다.

### Scene Description
어두운 새벽빛 공장 단지 위로 거대한 원형 데이터 허브가 떠 있고 허브에서 나온 빛줄기가 여러 생산 라인으로 부드럽게 흘러간다.
전경 왼쪽에는 안전모를 쓴 작업자 캐릭터가 태블릿을 들고 로봇 팔과 협업하며, 전경 오른쪽에는 자율주행 운반 로봇이 부품 컨테이너를 반짝이는 경로를 따라 이동한다.
중경에는 모듈형 공정 셀들이 육각형 패턴으로 배치되어 있고 각 셀 내부에서는 센서 구체, 검사 드론, 품질 신호등이 서로 반응하며 상태 변화를 표현한다.
후경에는 태양광 지붕과 에너지 저장 타워가 보이고, 에너지 흐름은 따뜻한 색 파동으로 공장 전체를 감싸며 지속가능한 운영의 맥락을 만든다.
상공에는 공급망 노드가 별자리처럼 연결되어 원자재, 생산, 출하, 재활용의 순환 경로를 원형 궤도로 나타내고, 중심 허브로 되돌아오는 루프가 반복된다.
질감은 플랫 벡터 기반으로 유지하되 미세한 글로우와 입자 효과를 사용해 데이터와 에너지의 움직임을 살아 있는 생태계처럼 보이게 한다.
화면의 모든 핵심 요소는 가장자리에서 충분한 여백을 두고 완전한 형태로 포함되어 잘림 없이 읽히며, 전경 중경 후경이 부드럽게 이어진다.
No watermarks, no text labels, no numbers, no placeholder brackets, no duplicated objects, no random artifacts.

### Rendering Style
- surface: 둥근 기하학 형태의 플랫 벡터 오브젝트로 구성하고 외곽선 대신 색면 대비로 형태를 구분한다.
- background: 어두운 단색과 미세한 대각선 그라데이션을 결합해 깊이 있는 무대를 만든다.
- corners: 모든 캐릭터와 사물의 모서리를 크게 라운딩해 친근한 시각 톤을 유지한다.
- connectors: 화살표 대신 빛나는 입자 흐름과 에너지 리본으로 관계와 이동을 표현한다.
- decorations: 작은 보케, 입자, 글로우 파동만 제한적으로 사용해 과밀 장식을 방지한다.
- spatial: 전경의 인물과 로봇, 중경의 공정 셀, 후경의 인프라와 하늘 네트워크로 삼중 레이어를 구성한다.
- metaphor: 스마트 팩토리를 자가 순환하는 생태계로 묘사해 기술과 운영의 상호 의존성을 시각화한다.
