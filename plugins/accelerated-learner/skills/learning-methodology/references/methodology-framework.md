# methodology-framework

## 블룸 분류체계 상세 (6단계)

학습 설계 시 하위 인지 수준(기억, 이해, 적용)에만 머물지 않고 상위 인지 수준(분석, 평가, 창조)으로 이동하도록 질문을 구성한다.

1. **기억 (Remember)**
   - 핵심 용어, 사실, 절차를 재생한다.
   - 신호: "정의하라", "나열하라", "식별하라"
2. **이해 (Understand)**
   - 개념을 자신의 언어로 설명하고 의미를 해석한다.
   - 신호: "요약하라", "설명하라", "예를 들어라"
3. **적용 (Apply)**
   - 규칙/방법을 새로운 문제에 사용한다.
   - 신호: "적용하라", "실행하라", "계산하라"
4. **분석 (Analyze)**
   - 구조를 분해하고 관계·원인을 파악한다.
   - 신호: "비교하라", "분해하라", "원인을 추적하라"
5. **평가 (Evaluate)**
   - 기준을 세워 대안을 판단하고 정당화한다.
   - 신호: "판단하라", "비판하라", "우선순위를 정하라"
6. **창조 (Create)**
   - 요소를 재조합해 새로운 해결안을 설계한다.
   - 신호: "설계하라", "제안하라", "재구성하라"

실무 원칙:

- 판별 질문은 Analyze/Evaluate/Create를 중심으로 설계한다.
- Remember/Understand 질문은 워밍업 용도로만 제한적으로 사용한다.
- 하나의 질문 안에 최소 2개 이상의 인지 동작(예: 비교+평가)을 결합하면 분별력이 높아진다.

## 소크라틱 메서드 질문 유형 (6종)

1. **명확화 질문 (Clarification Questions)**
   - 목적: 모호한 표현을 구체화
   - 예: "여기서 ‘효율’은 시간, 비용, 정확도 중 무엇을 의미하나요?"

2. **가정 탐색 질문 (Probing Assumptions)**
   - 목적: 답변 뒤에 숨은 전제 확인
   - 예: "그 결론이 성립하려면 어떤 전제가 반드시 참이어야 하나요?"

3. **증거 탐색 질문 (Probing Evidence)**
   - 목적: 주장과 근거의 연결 점검
   - 예: "그 주장을 지지하는 데이터나 사례는 무엇인가요?"

4. **관점 전환 질문 (Questioning Viewpoints)**
   - 목적: 대안적 시각 검토
   - 예: "반대 입장에서는 이 결론을 어떻게 비판할까요?"

5. **결과 탐색 질문 (Probing Implications)**
   - 목적: 선택의 파급효과 예측
   - 예: "이 접근을 확장 적용하면 어떤 부작용이 발생할 수 있나요?"

6. **질문에 대한 질문 (Questioning the Question)**
   - 목적: 문제 정의 자체를 재검토
   - 예: "우리가 지금 풀어야 할 핵심 질문이 맞는지 다시 점검해볼까요?"

운영 팁:

- 동일 유형 질문만 반복하지 말고, 세션 내에서 6종을 순환 배치한다.
- 교정 피드백 직후에는 명확화/가정 탐색 질문이 효과적이다.
- 고급 학습자에게는 관점 전환 + 결과 탐색 조합이 깊이를 만든다.

## 판별 질문 예시 패턴 (분야별)

### 공학/기술 분야

- "A 아키텍처와 B 아키텍처를 장애 복구 관점에서 비교하고, 실제 운영환경에서 더 적합한 선택을 정당화하세요."
- "현재 시스템 병목의 1차 원인을 가정-검증 형태로 분해하고, 잘못된 가정이 있으면 어떻게 수정할지 설명하세요."
- "동일 요구사항을 만족하는 대체 설계를 제시하고, 성능·유지보수·안전성 트레이드오프를 평가하세요."

### 경영/전략 분야

- "시장 점유율 확대 전략 X와 수익성 방어 전략 Y 중 우선순위를 결정하고, 의사결정 기준을 명시하세요."
- "제시된 지표가 실제 경쟁우위를 반영하지 못하는 이유를 비판적으로 분석하세요."
- "반대 시나리오(경기침체/규제강화)에서 현재 전략이 실패하는 경로를 설명하고 보완안을 설계하세요."

### 교육/인문사회 분야

- "이론 A와 이론 B가 학습 동기를 설명하는 방식의 근본 차이를 비교하세요."
- "같은 현상을 서로 다른 문화적 맥락에서 해석할 때 결론이 어떻게 달라지는지 논증하세요."
- "주장에 내재된 가치판단을 분리하고, 증거 기반 주장을 재구성하세요."

### 데이터/AI 분야

- "모델 성능 향상 결과가 데이터 누수 없이 타당한지 검증 절차를 설계하세요."
- "정확도 중심 평가가 왜 위험한지 설명하고, 대체 평가 프레임워크를 제안하세요."
- "편향 완화를 위한 개입 지점을 데이터 수집-전처리-학습-배포 단계로 나눠 우선순위화하세요."

사용 지침:

- 예시를 그대로 복사하지 말고 도메인 용어만 교체해 적용한다.
- 질문은 단일 정답 유도가 아니라 추론 과정 노출을 목표로 한다.
- 최종 질문 세트는 학습자 수준에 맞춰 난이도를 계단식으로 구성한다.
