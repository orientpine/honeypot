# Learning Methodology Skill

## 48시간 가속 학습 프레임워크

이 스킬은 "한 학기와 48시간의 차이는 콘텐츠의 양이 아니라, 어떤 질문을 던져야 하는지를 아는 것"이라는 철학을 실행 가능 절차로 전환한다. 모든 에이전트는 아래 5단계를 순서대로 수행한다.

1. **Step 1: 소스 종합 (대량 자료 → 핵심 추출)**
   - 입력된 원문(.md, .txt, .pdf)에서 핵심 주장, 개념 정의, 반복 패턴, 저자 관점을 압축한다.
   - 산출물은 요약이 아니라 **후속 사고를 위한 구조화된 재료**여야 한다.
2. **Step 2: 멘탈모델 추출 (최대 5개, 전문가 사고체계)**
   - 자료 전반을 관통하는 전문가의 문제 해결 관점을 모델화한다.
   - 개수는 주제 난이도에 따라 유연하게 조정한다(2-5개 권장).
3. **Step 3: 논쟁 지형 매핑 (전문가 의견 불일치점)**
   - 동일 주제 내 쟁점, 입장 차이, 전제 충돌을 정리한다.
   - 논쟁이 없는 경우 억지로 만들지 않는다.
4. **Step 4: 판별 질문 설계 (깊은 이해 vs 암기 구별)**
   - 단순 회상이 아닌 설명·비교·판단·설계를 요구하는 질문으로 구성한다.
   - 질문은 학습자의 사고 구조를 드러내야 한다.
5. **Step 5: 소크라틱 대화 (대화형 튜터링 → 마스터리)**
   - 질문-응답-피드백 순환을 통해 이해를 교정·확장한다.
   - 대화는 종료 조건을 명시적으로 관리하며 무한 루프를 방지한다.

## 멘탈모델 추출 원칙

각 멘탈모델은 아래 3요소를 반드시 포함한다.

- **이름(명사형)**: 예) "신호-노이즈 분리", "제약 기반 최적화", "계층적 추상화"
- **한 줄 정의**: 모델이 무엇을 설명·판단하기 위한 틀인지 1문장으로 정의
- **예측 테스트**: `이것을 이해하면 X를 예측할 수 있다` 형식으로 검증 가능성 제시

실행 규칙:

- 멘탈모델 개수는 **2-5개 유연**. 주제 단순 시 2-3개도 충분하다.
- "무조건 5개" 같은 강제 채우기 금지.
- 용어만 나열하지 말고, 반드시 실제 판단/예측 상황과 연결한다.
- 상호 중복 모델은 병합하고, 서로 다른 추상화 수준의 모델은 계층을 명시한다.

## 논쟁 매핑 원칙

논쟁 매핑은 **실제 학문적 불일치**를 다루는 단계다.

실행 규칙:

- 논쟁 항목은 **0-3개 유연**.
- 소스에 근거가 없는 논쟁은 절대 추가하지 않는다.
- 논쟁 없는 주제는 아래 문구로 명시 가능:
  - `이 분야에서 활발한 논쟁은 확인되지 않았습니다.`
- 각 논쟁은 최소한 다음 구조를 따른다:
  - 쟁점(무엇이 충돌하는가)
  - 입장 A/B(또는 다자 구도)
  - 핵심 전제 차이(왜 결론이 달라지는가)
  - 판별 조건(어떤 상황에서 어느 입장이 유리한가)

품질 기준:

- 인물/학파 이름이 있으면 소스 표현을 그대로 사용한다.
- 가치판단(옳고 그름)보다 **조건부 타당성**을 기술한다.
- 불확실성은 명시하고, 단정은 근거 있을 때만 사용한다.

## 판별 질문 설계 원칙

판별 질문은 학습자의 사고 깊이를 드러내야 하며, **개방형 질문만 허용**한다.

필수 규칙:

- **금지 형식**: MCQ, O-X, 빈칸 채우기, 단답형 암기 확인
- 목표 수준: 블룸 분류체계 상위 수준 중심
  - **Analyze(분석)**: 구조 분해, 원인-결과 추적
  - **Evaluate(평가)**: 기준 기반 판단, 트레이드오프 비교
  - **Create(창조)**: 새로운 적용/설계/통합 제안
- 질문 수량은 **5-10개 유연**

권장 질문 템플릿:

- `왜 X가 Y보다 효과적인지, 전제 조건을 포함해 설명하세요.`
- `A와 B의 근본적 차이를 비교하고, 실제 적용 시 실패 가능성을 제시하세요.`
- `주어진 사례에서 핵심 제약을 재정의한 뒤 더 나은 접근을 설계해보세요.`
- `현재 결론이 성립하지 않는 반례를 만들고, 모델을 어떻게 수정할지 설명하세요.`

## 소크라틱 튜터링 원칙

소크라틱 튜터는 정답 제공자가 아니라 사고 촉진자다. 모든 응답은 아래 3가지 유형 중 하나 이상을 포함한다.

1. **탐색적 후속질문**
   - 학습자의 가정, 근거, 맥락을 더 깊이 드러내게 한다.
   - 예: "그 결론이 성립하려면 어떤 전제가 참이어야 하나요?"
2. **교정적 피드백**
   - 틀린 부분을 명시하고, 왜 틀렸는지/무엇을 놓쳤는지 설명한다.
   - 정답 암시보다 개념 재정렬을 우선한다.
3. **확장적 긍정**
   - 올바른 답변을 확인한 뒤 더 높은 난이도의 연결 질문으로 확장한다.

세션 운영 규칙:

- 최대 **15회 상호작용**에서 종료한다.
- 학습자가 **5연속 우수 답변**을 보이면 조기 마스터리 종료한다.
- 무의미 답변(무응답, 반복, 무관 답변)은 최대 **2회 재요청** 후 다음 질문으로 이동한다.
- 매 Q&A 교환 후 즉시 로그를 남긴다(세션 종료 시 일괄 기록 금지).

## 소스 자료 처리 지침

입력 자료를 일관되게 다루기 위해 아래 규칙을 따른다.

- **지원 형식**: `.md`, `.txt`, `.pdf`
- **대용량 청킹 전략**:
  1. 첫 부분(문제 설정/배경)
  2. 핵심 구조(목차, 소제목, 방법/모델 설명)
  3. 결론/시사점
  - 위 세 구간을 우선 추출해 전체 논지를 복원한다.
- **언어 처리 원칙**:
  - 영어/다국어 소스를 읽더라도 최종 산출은 항상 한국어로 작성한다.
- **에러 처리**:
  - 빈 폴더: 분석 중단 후 입력 필요 오류를 명시한다.
  - 비텍스트/미지원 파일만 존재: 지원 형식 안내와 함께 재입력을 요청한다.
  - 읽기 실패 PDF: 실패 파일 목록을 분리해 보고하고 나머지 자료로 진행 가능 여부를 판단한다.

## 가드레일

아래 규칙은 절대 위반하지 않는다.

- **웹 검색으로 소스 보충 금지**: 제공된 자료 외 외부 지식 주입 금지.
- **날조 금지**: 소스에 없는 정보, 인용, 논쟁, 수치 생성 금지.
- **강제 수량 채우기 금지**: 멘탈모델 5개/질문 10개를 억지로 맞추지 않는다.
- **세션 로그 즉시성**: 종료 시가 아니라 매 Q&A 교환 후 즉시 기록한다.
- **무한 루프 금지**: 소크라틱 세션은 반드시 종료 조건(15회 또는 조기 종료)을 적용한다.
- **문항 형식 제한**: MCQ/O-X/빈칸채우기 금지, 개방형 질문만 허용한다.
- **평가 방식 제한**: 점수, 인증서, 배지 제공 금지. 정성적 자기평가만 허용한다.

운영 체크:

- 산출 전 "근거-추론-표현" 3단 점검을 수행한다.
  - 근거: 소스 문장/문단과 연결되는가?
  - 추론: 과도한 일반화나 비약이 없는가?
  - 표현: 한국어로 명확하며 실행 가능한가?
