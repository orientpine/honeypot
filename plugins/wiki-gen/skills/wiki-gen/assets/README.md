# Wiki-Gen Agent Templates

This directory contains reusable markdown prompt templates for orchestrating parallel sub-agents in the wiki-gen workflow. These templates ensure consistent quality, tone, and structural integrity across large-scale wiki generation tasks.

## Templates

| File | Description |
|------|-------------|
| `absorb_agent.md` | Initial absorption of raw entries into wiki articles. |
| `remediation_agent.md` | Targeted filling of citation gaps to reach 100% coverage. |
| `cleanup_agent.md` | Auditing, restructuring, and merging existing articles. |
| `breakdown_agent.md` | Identifying and creating missing articles for high-reference entities. |

## Standard Placeholders

Orchestrator agents must replace these placeholders before spawning a sub-agent:

- `{BATCH_ID}`: Unique identifier for the current batch (e.g., `B01_personal_project` or `B05_work_area` generated by `scripts/generate_batches.py`).
- `{TARGET_DIR}`: The specific `wiki/<dir>/` path this agent owns and writes to.
- `{ENTRY_COUNT}`: Total number of raw entries assigned to this batch.
- `{BATCH_MANIFEST_PATH}`: Absolute path to the JSON manifest listing entries for this batch.
- `{WIKI_ROOT}`: Absolute path to the root `wiki/` directory.
- `{ENTRIES_DIR}`: Absolute path to the `raw/entries/` directory.

## Usage

When delegating a task to a sub-agent, read the relevant template, replace the placeholders with actual values, and pass the resulting text as the prompt.

Example:
1. Read `absorb_agent.md`.
2. Replace `{BATCH_ID}` with a concrete batch id like `B01_personal_project`.
3. Replace `{TARGET_DIR}` with `/home/cha/Documents/wiki/ai_research/`.
4. ... and so on for all placeholders.
5. Use the `Task` tool with the populated prompt.

## Writing Standards Reference

All agents must adhere to the standards defined in `SKILL.md`:
- Wikipedia tone (flat, factual, encyclopedic).
- No em dashes.
- No peacock words or editorial voice.
- Dual citation discipline (frontmatter + body).
- ASCII snake_case filenames.
