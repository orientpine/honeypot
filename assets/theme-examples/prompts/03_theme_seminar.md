## INSTRUCTION

### Image Purpose
AI 기반 연구 혁신 전략을 학술 발표 청중과 정책 담당자가 한눈에 이해할 수 있도록 에디토리얼 매거진 스타일의 세미나 슬라이드를 생성한다.

### Target Audience
대학 연구자, 정부 출연 연구기관 PM, AI 정책 담당자, 학술 발표 청중.

### Key Message
AI 기반 연구 자동화 기술이 연구 생산성을 획기적으로 향상시키고 있으며, 이를 국책과제에 적용하는 전략을 제시한다.

### Scene Description
화면 중앙에는 4개의 아이소메트릭 3D 아이콘이 매거진 에디토리얼 레이아웃으로 배치된다. 좌상단에는 대형 헤드라인 텍스트가 배치되고, 우측에는 3D 아이콘들이 다이나믹하게 배열된다. 각 아이콘은 받침대 없이 독립적으로 부유하며, 포토리얼리스틱한 재질감(금속, 유리, 플라스틱)을 가진다. 배경은 밝은 오프화이트로 유지하고, 아이콘 하단에는 미세한 접촉 그림자만 허용한다. 섹션 구분은 소프트 라운딩(12px)의 2D 영역으로 표현하며, 섹션 간 연결선은 2px 실선 + 열린 삼각형 화살표로 정보 흐름을 명확히 한다. 텍스트와 3D 아이콘이 서로 얽히며 시각적 리듬을 형성하고, 대형 제목 텍스트가 그래픽 요소 역할을 겸한다. 전체 공간은 텍스트(55-65%)와 3D 아이콘(35-45%)이 의도적으로 비대칭으로 배치되어 생동감을 부여한다. 격자 기반이되 오버사이즈 아이콘이나 블리드 텍스트로 격자를 의도적으로 깨는 요소를 1-2개 배치한다. 아이소메트릭 3D 아이콘과 텍스트 블록이 캔버스 면적을 최대한 활용하도록 배치되어, 시각적 밀도가 높은 매거진 에디토리얼 레이아웃을 형성한다. No watermarks, no blurry text, no placeholder brackets, no pedestals under 3D icons.

### Rendering Style
- 서피스: 아이소메트릭 포토리얼리스틱 3D 아이콘. 45도 아이소메트릭 시점. 각 핵심 개념을 받침대 없이 독립된 3D 오브젝트로 표현. 사실적 재질감(금속, 유리, 플라스틱, 목재, 콘크리트)과 소프트 스튜디오 라이팅 + 앰비언트 오클루전. 오브젝트 하단에 미세한 접촉 그림자만 허용.
- 배경: 깨끗한 단색 배경(팔레트 배경색). 배경에 미세한 그림자만 허용. 도트 그리드, 패턴 장식 금지. 3D 아이콘이 배경 위에 부유하는 듯한 깨끗한 공간감.
- 코너/엣지: 섹션 구분은 소프트 라운딩(12px radius)의 2D 섹션 영역. 섹션 테두리는 1px 보조색 실선 또는 배경색 차이로 구분. 3D 아이콘은 받침대 없이 깨끗한 외형 윤곽 유지.
- 연결선: 2D 평면 위의 깨끗한 플로우 라인. 2px 실선 + 열린 삼각형 화살표(▷). 보조색 사용. 곡선(Bezier) 연결 허용.
- 시각장식: 3D 아이콘 자체가 주요 시각 장식. 아이콘과 텍스트가 매거진 에디토리얼 스타일로 어우러짐. 텍스트가 3D 아이콘 주변을 감싸거나 아이콘 위아래로 다이나믹하게 배치. 섹션 헤더는 대형 볼드 텍스트로 시각적 앵커 역할. 색상 범례 박스, 축 라벨, 데이터 테이블 금지.
- 공간구성: 매거진 에디토리얼 레이아웃. 2D 텍스트(55-65%)와 3D 아이소메트릭 아이콘(35-45%)이 다이나믹하게 배치. 텍스트와 아이콘이 기계적으로 분리되지 않고 서로 얽히며 시각적 흐름 형성. 격자 기반이되 격자를 의도적으로 깨는 요소 1-2개 배치. 의미적으로 중요한 3D 아이콘을 할당 영역보다 크게 렌더링하여 캔버스 밀도를 높인다. 네거티브 스페이스 ≤15% 목표.
- 시각메타포: 에디토리얼 매거진 × 아이소메트릭 3D. 고급 과학잡지의 인포그래픽처럼 정보와 시각적 매력을 동시에 전달. 추상 개념을 구체적 사물/장비로 번역하여 받침대 없이 독립된 3D 오브젝트로 배치. 대형 헤드라인 텍스트와 3D 아이콘이 서로 시각적 대화를 이루는 역동적 구성.
