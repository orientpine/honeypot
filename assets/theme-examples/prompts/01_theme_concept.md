# INSTRUCTION

### Image Purpose
스마트 팩토리의 AI 혁신 과정을 시각적 메타포로 설명하는 교육용 일러스트레이션. 텍스트 없이 장면과 캐릭터 행동만으로 자동화, 데이터 흐름, 지능형 의사결정의 개념을 전달한다.

### Target Audience
기술 혁신에 관심 있는 일반 대중, 산업 종사자, 학생, 정책 입안자.

### Key Message
공장의 인간 노동자가 AI 기술과 협력하여 더 효율적이고 안전한 미래를 만들어가는 과정.

### Visual Style
Kurzgesagt 풍 시각 스토리텔링. 채도 높은 플랫 벡터 일러스트로 복잡한 개념을 한 장면에 담는다. 텍스트 없이 시각적 메타포와 캐릭터 행동으로만 정보를 전달한다.

### Rendering Style
- 서피스: 플랫 벡터 일러스트레이션. 둥근 기하학적 형태와 부드러운 곡선. 각 도형은 단일 고채도 색상으로 채움. 테두리 없음. 그림자는 같은 색의 어두운 톤으로 최소한만 사용.
- 배경: 어두운 단색(딥 스페이스 #1B2838) 또는 미세한 대각선 그라데이션. 배경에 미세한 별/입자/보케 2-4개 허용. 배경은 전경 요소를 돋보이게 하는 무대 역할.
- 코너/엣지: 모든 형태에 큰 라운딩 적용. 날카로운 모서리 없음. 캐릭터와 사물 모두 부드럽고 친근한 형태.
- 연결선: 연결선 대신 시각적 근접성과 행동으로 관계를 표현. 필요 시 빛나는 입자 흐름(glowing particle stream) 또는 에너지 선(energy beam)으로 연결.
- 시각 장식: 빛나는 글로우 효과(glow), 작은 빛 입자(particles), 반투명 원형 보케, 에너지 파동(ripple). 플랫하되 깊이감을 빛과 레이어로 표현.
- 공간 구성: 풀블리드(edge-to-edge) 장면. 전체 캔버스를 하나의 연속된 장면으로 활용. 전경-중경-후경의 3레이어 깊이감. 핵심 요소는 화면의 1/3 지점에 배치(삼분법). 세이프 존: 모든 핵심 시각 요소(캐릭터, 주요 오브젝트, 행동의 결과물)는 캔버스 가장자리에서 5% 이상 안쪽에 완전히 포함되어야 한다.
- 시각 메타포: 시각 스토리텔링. 복잡한 개념을 일상적 장면이나 판타지 세계로 번역. 추상 개념을 물리적 사물로 의인화. 스케일 대비(거대 vs 미소)로 중요도 표현. 인과관계를 장면 내 행동 시퀀스로 보여줌.

### Content Placement
우주 배경에 거대한 공장 건물 실루엣이 서 있고, 창문에서 따뜻한 빛이 새어나온다. 공장 굴뚝에서 데이터 패킷 형태의 빛나는 구체들이 솟아오르며, 하늘에는 AI 뇌 형태의 홀로그램이 떠 있고 공장과 연결선으로 이어져 있다. 전경에는 작은 로봇 캐릭터들이 데이터를 운반하고 있으며, 배경에는 별자리처럼 연결된 네트워크 노드들이 빛나고 있다. 공장 내부에서는 인간 노동자와 로봇이 함께 작업하는 모습이 창문을 통해 보인다. 모든 요소는 시안색(#00BCD4) 글로우와 오렌지색(#FF6F00) 강조로 에너지와 혁신의 느낌을 전달한다. No text, no labels, no numbers, no watermarks, no blurry elements.

- layout: central

### Background Treatment
- base: 어두운 단색 배경 (딥 스페이스 #1B2838)
- texture: 미세한 대각선 그라데이션
- accent_elements: 별/입자/보케 2-4개

### Color Palette
- primary: #1B2838 (딥 스페이스) - 배경, 깊이감
- secondary: #00BCD4 (일렉트릭 시안) - 기술 요소, 데이터 흐름, 연결선
- accent: #FF6F00 (비비드 오렌지) - 핵심 포인트, 에너지, 반응
- foreground: #E0F7FA (아이스 화이트) - 전경 요소, 하이라이트

### Layout Structure
Central layout with three depth layers:
- Foreground: 로봇 캐릭터들과 데이터 운반 행동
- Midground: 공장 건물과 AI 홀로그램 연결
- Background: 우주 환경, 별자리 네트워크, 그라데이션

### Typography
All Korean text must be rendered with crisp, perfectly formed characters using heavy-weight Gothic-style sans-serif fonts. Each Korean syllable block must be complete and legible. Use Bold weight (700+) for titles, Medium weight (500) for body text.
**CRITICAL: This theme renders NO text in the image. All information is conveyed through visual elements, character actions, and spatial composition.**
