## INSTRUCTION

### Image Purpose
AI 스마트 팩토리 2030 비전을 이미 구현된 미래 장면으로 보여주어, 의사결정자와 투자자가 성공한 세계를 직접 경험하게 한다. 자동화된 생산 라인, 실시간 AI 분석, 무인 운영 시스템이 일상적으로 작동하는 모습을 시네마틱하게 연출한다.

### Target Audience
제조업 경영진, 산업 정책 담당자, 기술 투자자, 스마트 팩토리 도입 검토 기업.

### Key Message
AI가 모든 생산 결정을 내리고 있다. 이것이 2030년의 표준이다.

### Visual Style
whatif 테마: 공상과학 영화 UI처럼 빛나는 HUD 속에서 미래 팩토리가 작동 중이다. 어두운 배경에 밝은 네온 강조, 글래스모피즘 패널, 실시간 데이터 시각화.

### Rendering Style
- 서피스: 반투명 홀로그래픽 패널(배경 블러 + 30% 투명도), 패널 테두리는 슬레이트 블루(#4ECDC4) 1px 글로우. 내부 텍스트는 밝은 톤.
- 배경: 미드나이트 틸(#1A535C) → 소프트 크림(#F7FFF7) 대각선 그래디언트. 좌하단 어두움에서 우상단 밝음으로 "어둠에서 밝은 미래로" 방향성 암시. 미세한 원형 보케 2-3개 추가.
- 코너/엣지: 큰 라운딩(16px radius). 일부 요소에 pill shape(완전 라운드) 허용. 미래적이고 유기적 느낌.
- 연결선: 그래디언트 선(슬레이트 블루 → 선셋 오렌지) + 빛나는 글로우 효과. 화살표 대신 흐르는 점선(animated dot line 느낌). 데이터 흐름과 에너지를 암시.
- 시각장식: 반투명 원형 보케, 가는 원형 링 장식, 작은 빛 입자(particle) 느낌의 도트. HUD/대시보드 UI 요소(게이지, 미니 차트, 홀로그래픽 디스플레이). 장면 속 자연스러운 UI 오버레이.
- 공간구성: 풀블리드(edge-to-edge) 장면. 배경이 화면 끝까지 채워진다. 콘텐츠가 장면 안에 자연스럽게 배치된다. 프레임/테두리 의식 없이 영화의 한 장면처럼 구성. 시각 요소가 캔버스 면적을 최대한 채우도록 스케일업하며, 네거티브 스페이스 ≤20% 목표.
- 시각메타포: 시네마틱 씬. 관리자/엔지니어가 환경 속에서 AI 시스템을 모니터링 중. 대시보드 UI가 공중에 떠 있다. 공간감 있는 장면 연출. 빛과 그림자로 깊이감을 표현.

### Scene Description
어두운 스마트 팩토리 관제실 중앙에 여러 개의 반투명 홀로그래픽 패널이 공중에 떠 있고, 각 패널에는 실시간 생산 데이터와 AI 분석 결과가 표시된다. 패널 테두리는 슬레이트 블루 글로우로 빛난다. 관리자는 태블릿을 들고 있으며 자신감 있는 표정으로 패널을 확인 중이다. 배경에는 자동화된 로봇 팔이 정밀하게 부품을 조립하고 있고, 컨베이어 벨트가 조용히 움직인다. 천장에서 부드러운 네온 라인이 생산 흐름을 따라 흐르고, 바닥에는 미세한 원형 보케가 떠 있다. 전체 장면은 미드나이트 틸의 어두운 톤에서 우상단으로 갈수록 밝아지는 그래디언트로 표현되어, "어둠에서 밝은 미래로" 나아가는 방향성을 암시한다. 모든 모서리는 부드러운 라운딩으로 처리되어 미래적이고 유기적인 느낌을 준다. 장면 전체에 걸쳐 작은 빛 입자들이 떠다니며 에너지와 데이터 흐름을 시각화한다. 관리자의 표정과 자세에서 완전한 신뢰와 통제감이 드러난다. 이것이 2030년의 일상이다. No watermarks, no blurry text, no placeholder brackets, no rounded corners on data panels.

### Content Placement
상단 중앙에 '2030 AI 스마트 팩토리' 제목을 가장 크게 배치하고, 그 아래 '완전 자동화 운영 중' 부제를 중간 크기로 정렬한다. 좌측 홀로그래픽 패널에는 '생산 효율 87% 향상', '불량률 0.3%' 수치를 배치하고, 우측 패널에는 '실시간 AI 분석', '예측 정확도 99.7%' 텍스트를 배치한다. 중앙 하단 패널에는 '무인 운영 시간 23시간 47분', '에너지 소비 42% 감소' 데이터를 표시한다. 관리자가 들고 있는 태블릿 화면에는 '전체 시스템 정상' 상태 표시를 배치한다. 배경 로봇 팔 위에는 '정밀도 ±0.1mm' 라벨을 작은 글씨로 배치한다. 천장 네온 라인을 따라 '데이터 흐름 실시간 추적' 텍스트를 흐르는 느낌으로 배치한다. 하단 우측에는 '기준일: 2030.01', '자료: AI 팩토리 통합 관제 시스템' 주석을 작은 톤으로 배치하되 본문 가독성을 방해하지 않도록 한다.
