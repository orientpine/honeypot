## INSTRUCTION

### Image Purpose
스마트 팩토리 투자 유치를 위한 피치덱 슬라이드를 생성한다. 투자자가 30초 내에 시장 기회와 우리의 경쟁력을 한눈에 파악할 수 있도록 핵심 숫자와 메시지를 강조한다.

### Target Audience
벤처캐피탈(VC), 엔젤 투자자, 산업 펀드 매니저, 기업 전략 담당자.

### Key Message
스마트 팩토리 시장은 연 35% 성장하고 있으며, 우리의 AI 기반 솔루션은 제조 불량률을 60% 감소시킨다.

### Scene Description
화면 전체는 어두운 배경(퓨어 블랙 기반 그래디언트)으로 채워지고, 중앙 좌측에 거대한 숫자("+340%")가 화면의 30% 이상을 차지하며 배치된다. 숫자 아래에는 한 줄의 설명("월간 활성 사용자 증가")이 중간 크기로 배치된다. 우상단에는 프로스티드 글래스 카드 하나가 반투명하게 떠 있으며, 카드 내부에는 밝은 텍스트("시리즈 A 50억원 모집")가 명확하게 읽힌다. 배경에는 미묘한 퍼플-블루 그래디언트 블롭이 유기적으로 배치되어 프리미엄 느낌을 더한다. 하단에는 미니 스파크라인 차트(밝은 색 상승 곡선)가 작게 배치되어 성장 추세를 시각화한다. 모든 텍스트는 밝은 색(스노우 화이트 또는 퍼플 강조)으로 어두운 배경과 극강의 대비를 이룬다. 카드의 테두리는 얇고 은은하게(1px, 흰색 15% opacity) 처리되어 우아한 느낌을 유지한다. 전체 공간은 의도적인 어두운 여백이 30% 이상 차지하여 핵심 메시지의 무게감을 극대화한다. 어떤 플레이스홀더, 깨진 텍스트, 불완전한 카드도 없어야 한다. 모든 시각 요소는 완전하고 의미적으로 일관되어야 한다. No watermarks, no blurry text, no placeholder brackets, no rounded corners on glass cards.

### Rendering Style
- 서피스: 프로스티드 글래스(frosted glass) 카드 — 반투명 배경(rgba(255,255,255,0.08)) + 1px rgba(255,255,255,0.15) 테두리 + 배경 블러(backdrop blur). 카드 내부 텍스트는 밝은 색(#F5F5F7). 카드가 어두운 배경 위에 은은하게 떠 있는 느낌. 불투명 흰색 카드 사용 금지.
- 배경: Apple 다크 그래디언트 — #000000(퓨어 블랙) 기반에 부드럽게 흐르는 컬러 워시. 좌상단에서 우하단으로 #1C1C4E(미드나이트 인디고) → #2D1B69(딥 퍼플) → #000000 대각선 그래디언트. 보조 블롭: #0A84FF(애플 블루) 15% opacity 원형 블롭 1개, #BF5AF2(애플 퍼플) 10% opacity 블롭 1개를 배경에 자연스럽게 배치. 그래디언트는 미묘하고 우아하게 — 네온이나 사이버펑크 느낌 금지.
- 코너/엣지: 중간 라운딩(16px radius). Apple 카드 스타일. 숫자 강조 블록은 pill shape(완전 라운드) 허용. 글래스 카드의 테두리는 얇고 은은하게(1px, 흰색 15% opacity).
- 연결선: 연결선 최소화. 쓸 경우 1px rgba(255,255,255,0.2) 점선. 숫자와 메시지가 자체로 연결을 나타낸다.
- 시각 장식: 그래디언트 컬러 워시(유기적 블롭) 배경 장식 1-2개. 핵심 숫자 뒤에 강조색(#BF5AF2) 은은한 글로우 효과. 미니 스파크라인 차트(밝은 색). 장식은 절제되고 우아하게 — 과도한 효과 금지.
- 공간 구성: 대담한 비대칭. 핵심 숫자가 좌측 또는 중앙 상단에 매우 크게. 나머지 요소들이 어두운 공간에 작게 흩어진다. Z-패턴 시선 유도. 30% 이상 의도적 어두운 여백. 어두운 배경의 깊이감이 콘텐츠를 더욱 부각시킨다. 핵심 숫자는 화면의 30% 이상을 차지하도록 스케일 최대화. 콘텐츠 영역 내 요소 크기 확대로 내부 밀도 향상.
- 시각 메타포: Apple 키노트 프레젠테이션. 어두운 무대 위의 스포트라이트처럼 핵심 메시지만 밝게 빛난다. 큰 숫자 카드, 미니 스파크라인, 프로스티드 글래스 패널. 프리미엄 테크 브랜드의 제품 발표 느낌.

### Content Placement
화면 좌측 중앙에 "+340%"를 가장 크게 배치하고, 그 아래에 "월간 활성 사용자 증가"를 중간 크기로 정렬한다. 우상단에는 프로스티드 글래스 카드를 배치하고, 카드 내부에 "시리즈 A 50억원 모집"을 밝은 색으로 배치한다. 카드 아래에는 "투자 자금 사용처: 기술 개발 60%, 마케팅 30%, 운영 10%"를 작은 텍스트로 배치한다. 하단 좌측에는 미니 스파크라인 차트(밝은 색 상승 곡선)를 배치하여 월간 성장 추세를 시각화한다. 하단 우측에는 "기준일: 2026.03"과 "자료: 스마트팩토리 시장 분석"을 작은 주석으로 배치하되 본문 가독성을 방해하지 않도록 대비를 낮춘다. 핵심 숫자 뒤에는 강조색(#BF5AF2) 은은한 글로우 효과를 추가하여 임팩트를 극대화한다.
