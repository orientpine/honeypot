## INSTRUCTION

### Image Purpose
디지털 전환 추진 현황을 평가위원과 정책 실무자가 한눈에 검토할 수 있도록 2x2 전략 박스 기반의 정부 보고형 슬라이드를 생성한다.

### Target Audience
정부 과제 평가위원, 공공기관 PM, 디지털 전환 실행 부서 책임자.

### Key Message
데이터 기반 실행 체계를 4대 전략으로 구조화해 추진 성과와 다음 단계 전환 계획을 동시에 제시한다.

### Scene Description
상단에는 강한 주조색 배너가 화면 폭 전체를 차지하고, 중앙 영역에는 2x2 정렬의 직사각형 패널 네 개가 일정 간격으로 배치된다. 각 패널은 선명한 실선 경계와 명확한 헤더 구획을 가지며, 본문 텍스트는 좌측 정렬로 정돈되어 공공 문서의 단정한 인상을 만든다. 배경은 밝은 중립 톤으로 유지하고 상단 배너와 하단 구분선이 문서 프레임을 고정해 시선이 흩어지지 않게 한다. 네 개 패널 사이에는 단방향 연결선과 채운 화살표를 배치해 추진 흐름이 좌상단에서 우하단으로 자연스럽게 읽히도록 구성한다. 코너와 엣지는 모두 완전 직각으로 처리하고 장식 요소는 단색 아이콘과 번호 배지로 제한해 정보 밀도를 유지한다. 전체 공간은 상단 배너, 본문 그리드, 하단 주석의 3단 구조를 따르며, 각 박스는 동일 크기와 간격으로 정렬되어 정책 실행 체계의 안정성을 시각적으로 은유한다. 네 개의 전략 박스가 캔버스 면적을 최대한 활용하도록 확장되어 배치되며, 박스 사이 여백은 내용 구분에 필요한 최소한으로 제한한다. No watermarks, no blurry text, no placeholder brackets, no rounded corners.

### Rendering Style
- 서피스: 모든 정보 단위는 실선 테두리의 직사각형 박스 안에 배치하고, 박스 헤더는 주조색 면처리 + 흰색 볼드 텍스트로 통일한다.
- 배경: 밝은 단색 배경 위에 상단 배너와 하단 구분선을 추가해 문서형 프레임을 형성한다.
- 코너/경계: 모든 박스, 선, 배너, 구분선은 완전 직각으로 처리하고 둥근 모서리는 배제한다.
- 연결선: 전략 박스 간 흐름은 굵은 실선 화살표로 연결하고 방향성은 좌상단에서 우하단으로 단일하게 유지한다.
- 시각장식: 단색 원형 아이콘, 번호 배지, 단순 불릿만 사용하며 과도한 일러스트 효과는 제거한다.
- 공간구성: 상단 15% 배너, 중앙 70% 2x2 그리드, 하단 15% 주석/요약 영역으로 분할한다. 그리드 박스가 캔버스 면적을 최대한 채우도록 확장하며, 네거티브 스페이스 ≤15%를 유지한다.
- 시각메타포: 정책 실행 로드맵을 4개 모듈로 구조화한 플랫 인포그래픽 메타포를 사용한다.

### Content Placement
상단 배너 중앙에 '디지털 전환 추진 현황'을 가장 크게 배치하고, 그 아래 오른쪽에 '2026년 1분기 성과 보고'를 중간 크기로 정렬한다. 상단 배너 하단 좌측에는 '범부처 데이터 기반 실행 체계 고도화'를 보조 문장으로 배치해 슬라이드의 핵심 방향을 즉시 읽히게 한다. 좌상단 박스 헤더에는 '01 데이터 수집 체계'를 배치하고 본문에는 '실시간 센서 연동 확대', '현장 단말 표준화 적용', '데이터 수집률 312% 증가'를 위에서 아래로 나열한다. 우상단 박스 헤더에는 '02 통합 분석 플랫폼'을 배치하고 본문에는 '통합 대시보드 운영', '이상 징후 자동 탐지', '분석 리드타임 43% 단축'을 동일한 줄간격으로 배치한다. 좌하단 박스 헤더에는 '03 업무 자동화 확산'을 배치하고 본문에는 '반복 행정 프로세스 자동화', '부서 간 연계 워크플로 적용', '수작업 처리 58% 감소'를 정렬한다. 우하단 박스 헤더에는 '04 성과 관리 체계'를 배치하고 본문에는 '성과 지표 상시 모니터링', '월간 실행 점검 정례화', '정책 반영 주기 2주 단축'을 구성한다. 하단 통합 요약 영역에는 '핵심 성과 요약', '생산성 27% 향상', '민원 처리시간 34% 단축', '서비스 오류 41% 감소'를 좌에서 우로 배치해 최종 효과를 강조한다. 각 전략 박스 좌상단에는 '01', '02', '03', '04' 번호 배지를 동일 크기로 배치하고, 박스 간 연결선 끝에는 채운 화살표를 넣어 실행 순서를 명확히 표시한다. 하단 우측에는 '기준일: 2026.03'과 '자료: 디지털혁신추진단 내부 집계'를 작은 주석으로 배치하되 본문 가독성을 방해하지 않도록 대비를 낮춘다.
